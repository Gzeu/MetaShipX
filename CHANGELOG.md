## [0.7.0] — 2026-05-24

### Added
- **`LEADERBOARD_ADDRESS`** in `frontend/src/config.ts` — 6th contract address,
  fail-fast `requireEnv('VITE_LEADERBOARD_ADDRESS')`, re-exported as
  `LEADERBOARD_CONTRACT_ADDRESS` constant used by service layer
- **`NETWORK_PROVIDER_URL`** export from `config.ts` — eliminates duplicate
  `import.meta.env.VITE_API_URL` access in service files
- **`getTopPlayers(limit?)`** — real on-chain decode replacing previous mock stub:
  - Queries `getTopPlayers` view on leaderboard contract
  - `decodeLeaderEntry()` parses TopEncode: `Address(32B) | u32 wins | BigUint egld_won | u32 games_played`
  - Converts egld_won from 10^18 denomination to 4-dp decimal string
  - Returns typed `LeaderEntry[]` — no more hardcoded offsets
- **`getPlayerRank(address)`** — queries `getPlayerRank` on leaderboard contract;
  returns 1-based rank, 0 if not in top-50
- **`getPlayerStats(address)`** — queries `getPlayerStats`; returns wins + egldEarned
- **`LeaderEntry` interface** exported from `battleship.service.ts` with `losses`
  derived field (`gamesPlayed - wins`)
- **`queryLeaderboard()`** private helper — routes queries to `LEADERBOARD_CONTRACT_ADDRESS`
- **`Leaderboard.tsx` rewrite** — on-chain data + UX improvements:
  - `Promise.all([getTopPlayers, getPlayerRank, getPlayerStats])` on load — single round trip
  - Auto-refresh every 30 s (safe Supernova cadence, no block spam)
  - "Your rank" + "wins · EGLD earned" badges in hero — pulled from contract, not mock
  - Podium top-3 shows EGLD earned + blue border highlight for own wallet
  - Full table: 7 columns (rank, player, wins, losses, win%, EGLD, games)
  - Tabs: "All-Time Top 50" (on-chain) + "Recent Activity" (v0.8.0 placeholder)
  - Empty state with CTA: "Win a game to appear on the leaderboard"
  - Refresh button with loading spinner
  - Last-updated timestamp
  - All `useColorModeValue` calls hoisted out of loop (React hooks lint compliance)

### Changed
- `battleshipService` export object updated — includes `getPlayerRank`, `getPlayerStats`
- `Leaderboard.tsx` — removed `useColorModeValue` calls inside `.map()` callbacks
  (React hooks-in-loop violation fixed)

### Notes for deploy
1. `VITE_LEADERBOARD_ADDRESS` must be set in `frontend/.env.local` (generated by `mainnet-deploy.sh`)
2. Leaderboard contract must be deployed and wired via `battleship.setLeaderboardContract(leaderboard_addr)` before data appears
3. Until wired, `getTopPlayers` returns empty array — empty state renders cleanly

## [0.6.0] — 2026-05-24

### Added
- **Leaderboard contract** (`contracts/leaderboard/`) — on-chain top-50 all-time by wins
  - `updatePlayer(player, egld_won)` — restricted to battleship contract caller
  - `getTopPlayers(limit)` — returns sorted `LeaderEntry[]` (wins desc, EGLD tiebreaker)
  - `getPlayerRank(address)` — returns 1-based rank, 0 if not ranked
  - `getPlayerStats(address)` — returns (wins, egld_won)
  - Insertion sort O(50), bounded and gas-safe
